# sebastianauner.com

Personal portfolio of Sebastian Auner, built with React.

## Development

```bash
npm install
npm start
```

Content lives in `src/portfolio.js`. The site is deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `master`.
